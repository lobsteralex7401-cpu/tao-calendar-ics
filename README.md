# 道場行事曆 訂閱用 .ics

發一崇德雲林道場道務行事曆，整理成手機可訂閱的日曆。內容只有活動名稱、日期、地點與分類，沒有人名。
行事曆以中心月會發佈為準，這裡會跟著更新；訂閱的手機會自動同步。

## 116 年（2027）

| 檔案 | 日曆名 | 內容 |
|---|---|---|
| `tao116_A.ics` | 116年道場_A_興禮必到 | 興禮班員、壇主講師一定要去的班程與研習 |
| `tao116_B.ics` | 116年道場_B_六順區派人 | 區或公壇要派人、輪值、祭祀拜年固定日 |
| `tao116_C.ics` | 116年道場_C_學界青少年 | 學界、青少年界 |
| `tao116_D.ics` | 116年道場_D_點傳師海外 | 點傳師班、海外班、中心層級 |
| `tao116_all.ics` | 116年道場_全部合併 | 以上全部一本 |

訂閱網址＝ `https://raw.githubusercontent.com/<帳號>/tao-calendar-ics/main/<檔案>`，
iPhone 用 `webcal://` 開頭同一路徑也可以。

產線在 claude-context repo 的 `tools/tao-calendar/`，資料正本是 `events_116.json`。
